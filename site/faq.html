FAQ

Frequently asked

What is PoorMad?

A self-improving AI agent built by one person, from a room. It writes its own skills, remembers across sessions, and gets sharper the longer you keep it. Not a service — yours.

Is my data private?

Local-first by default. Your memory and skills live in your PoorMad home. Nothing leaves your control unless you choose to connect a model or platform. Open source (MIT).

Which platforms are supported?

20+ surfaces: CLI, desktop (Windows/macOS), web portal, and messengers like Telegram, Discord, Slack, WhatsApp, Signal, and more. Full list on the docs.

How does it learn?

Through a loop of skills (experience → reusable, sharpened), memory (semantic recall across sessions), and orchestration (tools, subagents, scheduled jobs) — running locally.

Do I need an account?

No account is required to run the agent. The web portal adds optional accounts, billing, and hosting — coming on the Oracle VPS at portal.xingabot.com.

How do I install it?

pip install poormad-agent, or download the desktop app from the releases page. See the docs.

Is it open source?

Yes — MIT licensed. Built to be unique and yours only.
