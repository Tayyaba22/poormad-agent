Frequently asked questions

Everything you need to get started with PoorMad.

What is PoorMad?+
PoorMad is a self-improving AI agent. It writes its own skills from experience, remembers across sessions, and runs across your terminal, desktop, web portal, and 20+ messaging platforms. It's built to be unique and yours only.
Is PoorMad free / open source?+
Yes. PoorMad is MIT licensed and the source is on GitHub. You can self-host it on a $5 VPS or your laptop — no account required to start.
Which platforms does it support?+
A native desktop app, a terminal CLI with a TUI, a web portal, and 20+ messaging platforms including Telegram, Discord, Slack, WhatsApp, Signal, Matrix, Email, Teams, and Google Chat. Sessions resume across all of them.
How do I install it?+
Download a prebuilt installer from the download page (we detect your OS automatically), or run pip install poormad-agent then poormad setup.
Does it keep my data private?+
By default the agent runs on your own machine and memory stays in your PoorMad home. You choose which model provider to point it at. Nothing leaves your control unless you explicitly bind it to a hosted instance.
What is the web portal?+
The portal is a clean browser UI (Nous-Portal style) to chat, browse sessions, manage skills, and configure the agent. It's available at xingabot.com/portal and speaks the same gateway protocol as the desktop app.
How does it learn?+
When it solves something non-trivial, PoorMad can write a skill capturing the approach and reuse it next time. Its memory persists across sessions, so it builds a deepening model of your work without re-explaining.
Which models can it use?+
Any model you point it at — local, hosted, or a provider of your choice. The agent orchestrates tools and subagents around whatever backend you configure.
How do I update?+
Re-download the latest installer from the download page, or run poormad update from the terminal. Releases are published on GitHub.
Where do I get help?+
See the docs, open an issue on GitHub, or message the agent on your connected platform.
