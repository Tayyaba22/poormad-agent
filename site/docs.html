Getting started

PoorMad runs as a single agent behind a gateway. Every surface — CLI, desktop, web portal, messengers — connects to that gateway and shares the same memory.

Install

# Python
pip install poormad-agent

# or download the desktop app
→ github.com/.../releases

Connect a surface

# every surface talks JSON-RPC over WebSocket
from poormad import GatewayClient
client = GatewayClient("wss://your-agent.local/api/ws")
await client.connect()

The learning loop

Skills

When the agent solves something non-trivial, it writes a reusable skill, then sharpens it on the next run. Capability compounds locally.

Memory

A deepening model of who you are, searchable by meaning. No re-explaining context every session.

Orchestration

Tools, subagents, and scheduled jobs. Point it at any model and let it coordinate.

Portal

The web portal is where PoorMad meets you in a browser — chat, browse sessions, and manage skills. Accounts, billing, and hosting will live there. portal.xingabot.com →
