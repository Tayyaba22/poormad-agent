Documentation

PoorMad is a self-improving AI agent. It learns from experience, remembers across sessions, and runs across your terminal, desktop, web portal, and messaging platforms.

Install

Install the agent with pip, then run the setup flow:

pip install poormad-agent
poormad setup

Or grab a prebuilt installer from the download page — Windows, macOS, and Linux are supported.

Quick start

Launch the desktop app (which also starts the local gateway the portal connects to):

poormad desktop

Or talk to it straight from the terminal:

poormad "summarize my unread messages and draft replies"

Skills

Skills are PoorMad's reusable units of capability. When it solves something non-trivial, it can write a skill capturing the approach, then reuse it next time — so repeated work gets faster and more reliable.

  • Skills are plain, version-controlled files in your PoorMad home.
  • The agent curates and improves them as it uses them.
  • You can review, edit, or pin skills in the portal's Skills view.

Memory

PoorMad persists memory across sessions so it builds a deepening model of who you are and what you're working on. Past conversations are searchable via semantic recall — no re-explaining context every time.

Platforms

One agent, many surfaces. PoorMad connects to 20+ messaging platforms through a single gateway:

  • Telegram, Discord, Slack, WhatsApp, Signal, Matrix
  • Email (IMAP/SMTP), Microsoft Teams, Google Chat, LINE
  • And more — sessions resume across every platform.

Desktop & CLI

The desktop app is a native Electron build with the PoorMad house theme (space-black + violet, pixel-moon brand). The CLI and TUI give you the same agent in the terminal. All surfaces share one gateway and one memory.

Web Portal

The portal (Nous-Portal style) is a clean browser UI to chat, browse sessions, manage skills, and configure the agent — available at xingabot.com/portal. It speaks the same gateway protocol as the desktop app, so it's one agent, many front-ends.
